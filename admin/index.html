If this message stays put, the panel could not start. That is nearly always one of two things, both fixed in the Netlify dashboard and both one-off:

1. Netlify Identity is not enabled — Site configuration → Identity → Enable.
2. Git Gateway is not enabled — Identity → Services → Git Gateway → Enable.

See ADMIN.md in the repository for the full walkthrough, or go back to the website.
